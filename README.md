# -Beyond-diversity-a-whole-system-view-of-vegetations-control-of-erosion-data-and-code
Data and R code for the manuscript called: Beyond diversity: a whole system view of vegetation’s control of erosion

#Authors: Belen, J.C; Livsey, D.N; Martin, C.B; Groh, T.A; Cardinale, B.J

#The following files are included in this additional data for the paper: Appendix_S1 which is the supplementary, GE_DA_CabreraBelenJ.R is the R code, and the mastersheet.csv is the data utilized in the code. GE_bootstrap.R & relative_yield_1 is the R code for the bootstrapping procedure described in the manuscript and the data needed to execute it.
